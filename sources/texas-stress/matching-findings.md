# Texas matching and regression stress audit

Frozen input: `/tmp/turnout-texas-audit-20261025`, saved snapshot `2026-10-25T01:20:12.853006511+00:00`, through October 23 (day 5). No official sources or voter records were downloaded by this audit.

## Confirmed corrections

1. **Partial presidential aggregate fields can falsely imply a common-geography group's winner to API consumers.** `lib::analyze` previously summed whichever old-member returns existed. Missing returns correctly excluded the group from partisan margin buckets, and the public UI already checks complete presidential reference membership before assigning a share, color or winner cohort. Therefore this was a backend data-contract error; no displayed winner/color error is claimed. Now both presidential aggregate fields use the existing unknown convention (0/0) unless every old member has returns. Valid demographic turnout and population counts remain in All. Frozen latest-day exposure: 46 available groups in 16 counties, 169,675 historical and 139,022 current early in-person votes; partial raw sums implied 19 Harris and 25 Trump winners, while 2 were already unknown. All 46 were already displayed as unknown by the frontend guard. All 46 have all six Census demographic metrics; two also have primary classification. Details: `matching-partial-presidential.json`. These figures describe geography with corrected backend fields, not ballots removed from demographic All or a proved change to displayed winner cohorts.

2. **A downward cumulative revision could masquerade as a zero daily report.** The difference resolver omitted a negative precinct delta, but the complete-roster flag remained true; downstream matching inferred zero for that omitted precinct and retained its historical baseline. The minimal fixture incorrectly compared 20 historical votes with 2 current votes over two groups instead of 10 with 2 over one valid group. Cumulative values were valid and must remain. The resolver now materializes legitimate complete-roster zeroes using reference IDs before deriving differences, and a derived day with a negative correction is partial. Thus only invalid deltas are excluded; other explicit and implicit zeroes remain usable. No adjacent negative cumulative precinct was present in the frozen Texas snapshot, so this is protection against future corrections rather than a claimed correction to current totals.
