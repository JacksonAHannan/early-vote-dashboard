# Nueces current-publication failure

The final per-county refresh ledger found a remaining actual collector failure: `Nueces identifier layout changed`. A fresh official landing download discovered [the current dedicated in-person PDF](https://www.nuecesco.com/home/showpublisheddocument/34785/639287296761902535), SHA256 `c8d7d2bf4d4988422691faededb5a7b731bcb411eba9241031334695c6355c22`. Its nine explicitly dated sections contain 51,602 ordinary rows with the previously verified identifier layout, plus one seven-digit numeric identifier in precinct 17 on October 26. That single row rejected the entire cumulative document, leaving the dashboard at October 25. The contemporary October 27 SOS export also has 1,889 in-person observations, so native failure must not prevent the adapter from trying that independent source.

The recurring PDF parser now uses the existing shared `CountyRoster` quarantine mechanism: numeric identifiers outside the verified 8–10 digit layout are not accepted, padded or shortened. Their entire exact precinct/date cell is withheld; all independent valid observations survive. Ambiguous fields, unparseable dates, wrong methods, repeated identities and foreign calendar dates still fail. Missing dates are unavailable and do not invalidate posted dates. The adapter rediscovers the current county PDF each run and tries dated SOS reports only for native dates it could not supply, including after a native download/parser failure. It never mixes two sources within one date.

The actual old parser failed the new retained-observation assertion before implementation. Both parser tests now pass, including explicit quarantine of all rows in the affected cell, preserved other precincts/dates, missing-date nonzero-inference, and existing date/identity/method checks. An opt-in production test downloads the actual current PDF and passed in 8.23 seconds: all nine dates are returned; precinct 17 is absent and marked unavailable on October 26; October 27 retains at least 5,000 valid observations. Only anonymous aggregates and an invalid-row shape summary were persisted under `analysis/refresh-reliability`; the raw PDF, names and identifiers stayed in memory.

Cameron/Denton live probes also accept a subsequently fuller official state publication, instead of requiring the native alternative to remain selected after the publisher updates. Frozen parser fixtures continue testing native discovery and date/source contracts directly.
