# Texas precinct mail turnout: support boundary

Checked October 24, 2026, Central time. Latest completed comparison date is October 23, 2026 versus October 25, 2024: both are 11 days before their respective November elections. This bounded investigation uses official county/SOS publications and existing collector source. Firecrawl CLI was not authenticated, so live retrieval used the web tool and direct browser-compatible HTTPS. Voter rows were processed only in memory; retained evidence consists of counts, field names, dates, URLs and hashes.

## Decision for this implementation

**Keep the existing Texas precinct analysis explicitly in-person only.** The current precinct sources and historical caches deliberately exclude mail. County/state comparisons can use independently validated combined in-person plus received-mail totals. Availability of a mail ZIP does not establish a complete, dated, geographically compatible two-cycle precinct pipeline.

No county has passed all acceptance criteria below for adding mail to the current precinct regression/bucket pipeline in this investigation. Four counties have promising, directly inspected paired source families—Travis, Harris, Montgomery and Tarrant—but each has unresolved work. This finding preserves every currently available in-person comparison; it does not remove those counties or precincts.

Existing behavior is explicit in [`fetch.rs`](../../dashboard/src/fetch.rs) (`MAIL-IN` ignored), [`county.rs`](../../dashboard/src/county.rs) (dedicated in-person adapters), and [`trends.rs`](../../dashboard/src/trends.rs) (historical in-person aggregates). Reinterpreting their existing caches as combined turnout would silently produce the wrong denominator.

## Acceptance criteria before adding precinct mail

1. **Consistent measure.** Use returned/received ballots in both years when that is what the sources publish; use accepted ballots only if both cycles expose that measure. Never add applications or outgoing/sent ballots to turnout. SOS [publication guidance](https://www.sos.state.tx.us/elections/forms/qa-elections-division-10-20-2022-combined.pdf) treats sent and received rosters separately. A received ballot can still require later review.
2. **Full cumulative anchor.** Mail begins before in-person early voting. Current Montgomery's index begins September 23. Inspected Travis mail members alone contain 5,076 rows before October 19, 2026 and 8,897 before October 21, 2024, before resolving repeats; inspected Harris pre-start identity/date/precinct signatures total 22,553 and 25,050. A day-one cumulative combined count must include all verified earlier mail receipts. Do not fold those receipts into day-one **daily** turnout or assume the pre-start cumulative baseline is zero.
3. **Equivalent cutoffs.** Align by days before each election: October 23, 2026 matches October 25, 2024. Cumulative means all eligible receipts through that cutoff. Daily means that actual day's mail receipts plus in-person activity. Missing files, weekends, batch updates and day-one anchor totals must retain their own semantics.
4. **Maximum matched geography per observation.** For each date and measure separately, admit the largest comparable geography where both methods are known in both cycles. A missing mail report must not remove a county from the independently valid in-person view or remove its earlier complete dates. Confirmed zeros are usable; unreported precincts are not automatically zero. A combined county total must not become a synthetic precinct distribution.
5. **Identity and revision audit.** Remove only proven identical copies; supersede explicitly revised workbooks. Quarantine conflicting precinct/date assignments locally. Resolve cross-method overlaps while the raw data is transient: `fetch.rs` already documents that surrendered mail and valid in-person entries can share an identity. Neither blindly summing method aggregates nor arbitrarily dropping one method proves valid combined turnout. Preserve all unaffected precincts and observations.
6. **Geography and controls.** Map the published residence precinct identifiers through the existing cross-cycle groups. Do not truncate Tarrant's six-digit labels into map labels without an official correspondence. Reconcile each source/measure/date with independent county controls; leave the Tarrant 85-ballot daily SOS shortfall unallocated and visible in source evidence.
7. **Honest product scope.** Combined county/state headlines may be labeled “All early ballots” once their own paired controls pass. The current Texas precinct map, bucket analysis, regression, profile, CSV and PNG captions must continue to say “In person.” A county/state method selector must not silently change the precinct denominator. Winner filtering remains a subset of the selected validated regression cohort.

Its identity-value cardinality is diagnostic only and does not establish valid distinct voters or resolve missing identifiers.

Follow-up Harris implementation and real-data acceptance evidence are in [`harris-findings.md`](../../analysis/mail-turnout/harris-findings.md). That collector supersedes the initial Harris interpretation: the earlier signature audit skipped blank state identifiers, so its reduced cardinality did **not** prove repeated records. Stable county identifiers preserve those records without exposing identities. No native-mail source was admitted into the paired dashboard after the independent historical control comparison failed.

The subsequent standalone Harris collector remains inactive in dashboard refresh. No shared Rust module, dashboard view or admitted production dataset was changed by this investigation.
